## 👨‍💻 About Me

I'm a **Software Engineer** with three years of production experience at **PwC Acceleration Centers**, now pursuing an MS in Computer Science at UNC Charlotte. I like building things that actually run in production — not just prototypes.

- 🔧 **Full-stack development** — Java/Spring Boot back-ends and React front-ends. Three years shipping enterprise features for large client engagements.
- ☁️ **Cloud & data** — AWS and Azure integrations, REST APIs, data pipelines processing millions of records.
- 🤖 **Applied ML** — deploying real-time ML systems like [MotionLCM](https://huggingface.co/spaces/soumyanilain/MotionLCM), a text-to-motion generator based on the ECCV 2024 paper on latent consistency distillation.
- 🎯 **Currently seeking** — 2027 New Grad & Spring 2027 Co-op roles in software, data, cloud, or analytics. Open to relocation across the US.

### 🔭 What I'm Currently Building
